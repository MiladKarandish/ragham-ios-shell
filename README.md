# Ragham iOS shell — build inputs

A WKWebView shell around [web.raghamapp.com](https://web.raghamapp.com), built
here because `xcodebuild` only runs on macOS and the team has no Mac. GitHub's
macOS runners are free for public repositories, and the build is **unsigned** —
no Apple developer account, no certificates, no secrets. The market re-signs the
`.ipa`.

**This directory is generated.** It is exported from the private webapp repo by
`scripts/ios-shell-export.sh` and contains no application source — only the
Xcode project, the Capacitor config, icons, and the two build scripts. Edit
nothing here; change it upstream and re-export, or the next export reverts you.

## Building

Actions → *Build unsigned iOS shell* → **Run workflow**. Choose `stage` to point
the shell at beta.raghamapp.com instead. The `.ipa` is attached to the finished
run as an artifact.

## What is in this export

| Path | |
|---|---|
| `ios/` | the Xcode project, generated by `npx cap add ios` and committed |
| `capacitor.config.ts` | the whole native configuration |
| `native/www/` | a stub `index.html`; the shell loads the live site, not this |
| `scripts/ios-archive.sh` | `xcodebuild build` + hand-assembled `Payload/` |
| `scripts/ios-preflight.py` | the checks that otherwise fail silently |
| `package.json` | generated: version + the `@capacitor` packages only |

`ios-preflight.py` runs in `--native-only` mode here. Two of its checks read
`src/`, which deliberately does not travel; the exporter runs the full set
before writing this directory.
